# Optimal packing of disks with radii 1 through 9

This directory contains the supplied manuscript and computer-assisted proof
bundle for the minimum circular container problem with disks of radii
`1, 2, ..., 9`.

- `optimal_nine_integer_disks.pdf`, `optimal_nine_integer_disks.tex` — proof document and source.
- `certify_integer_nine_global.py`, `verify_nine_upper.py`, `verify_nine_global_tree.py` — certificate and bound verifiers.
- `gen_nine_global_tree.py` — certificate-tree generator.
- `nine_global_proof_tree.json` — finite proof-tree data.
- `integer_nine_global_proof_bundle.zip` — original supplied bundle.
