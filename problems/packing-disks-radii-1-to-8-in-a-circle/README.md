# Optimal packing of disks with radii 1 through 8

This directory contains the supplied manuscript and computer-assisted proof
bundle for the minimum circular container problem with disks of radii
`1, 2, ..., 8`.

- `optimal_eight_integer_disks.pdf`, `optimal_eight_integer_disks.tex` — proof document and source.
- `README_INTEGER_EIGHT_GLOBAL_PROOF.md` — theorem statement and proof-scope notes.
- `certify_integer_eight_global.py`, `verify_eight_upper.py`, `verify_eight_global_tree.py` — certificate and bound verifiers.
- `gen_eight_global_tree.py` — certificate-tree generator.
- `eight_global_proof_tree.json` — finite proof-tree data.
- `integer_eight_global_proof_bundle.zip` — original supplied bundle.
