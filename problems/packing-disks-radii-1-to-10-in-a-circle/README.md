# Optimal packing of disks with radii 1 through 10

This directory contains the supplied manuscript and computer-assisted proof
bundle for the minimum circular container problem with disks of radii
`1, 2, ..., 10`. The bundle's README describes its exact-arithmetic trust
boundary and limitations.

- `optimal_ten_integer_disks.pdf`, `optimal_ten_integer_disks.tex` — proof document and source.
- `README_INTEGER_TEN_GLOBAL_PROOF.md` — theorem statement and proof-scope notes.
- `certify_integer_ten_global.py`, `verify_ten_upper.py`, `verify_ten_global_tree.py` — certificate and bound verifiers.
- `gen_ten_global_tree.py`, `check_five_big_witness.py` — tree generator and rational witness checker.
- `ten_global_proof_tree.json` — finite proof-tree data.
- `TEN_SHA256SUMS.txt` — source bundle checksums.
- `integer_ten_global_proof_bundle.zip` — original supplied bundle.
